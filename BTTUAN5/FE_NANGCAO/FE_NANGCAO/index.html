01 / Kiến thức

Hôm nay học gì?

Nội dung được tổng hợp từ bài HTML và ảnh minh chứng trong tài liệu của buổi học.

01 — LAYOUT

Responsive Design

Thiết lập hai vùng LEFT / RIGHT: ban đầu chia chiều rộng 70% và 30%, chuyển về 100% khi màn hình thu nhỏ.

02 — CSS

Media Queries

Dùng mốc 768px để đổi bố cục; khoảng 320–480px ẩn vùng RIGHT; khi in ẩn vùng LEFT bằng @media print.

03 — HTML

Responsive Images

Tìm hiểu thẻ <picture>, <source> và srcset để chọn logo theo kích thước màn hình.

04 — JAVASCRIPT

Chrome DevTools & Console

Thực hành mở công cụ dành cho nhà phát triển, nhập lệnh JavaScript trong Console và quan sát kết quả trả về. Qua trò Dino, bài học minh họa việc gán lại hàm bằng Arrow Function và thử thay đổi hành vi của game.

05 — SYNTAX

Arrow Function

Phân biệt hàm rỗng () => {} và hàm nhận tham số (value) => {...} khi viết mã JavaScript.

02 / Thực hành

Bài làm của mình

Liên kết trực tiếp tới file bài tập và tài liệu minh chứng nằm cùng thư mục.

Bài 01 · HTML & CSS

Bố cục responsive

Trang Bai1.html có hai khối màu xanh / đỏ và các điều kiện Media Query theo yêu cầu trên lớp.

@media (max-width: 768px) {
.left, .right { width: 100%; }
}
